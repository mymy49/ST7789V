Detailed Description

Hardware-accelerated 2D drawing canvas bridge for ST7789V displays in Little-Endian RGB565 format.

ST7789V_with_Brush_RGB565 utilizes multiple inheritance:

  • ST7789V (local module): Provides register access, hardware window clipping, and display orientation controls.
  • BrushTftLcdRgb565LE (from the TurtleShip submodule): Provides device-independent 2D drawing primitives (lines, circles, rectangles, fonts, and bitmaps) designed for direct TFT LCD surfaces.

By overriding the hardware primitives (drawDot(), fillRectBase(), fillDotArray(), and drawBitmapBase()), this class transfers pixel drawing commands directly to the ST7789V controller memory without requiring a full-screen framebuffer in system RAM. Off-screen sub-regions are streamed through an optional working framebuffer (mFb).

Example Usage in Application

#include <ST7789V/ST7789V_spi_with_Brush_RGB565.h>
// Usually accessed via a board-level driver such as Touch_LCD_Shield_for_Arduino_2_8_inch
extern Touch_LCD_Shield_for_Arduino_2_8_inch lcd;
void drawShapes(void)
{
lcd.lock();
lcd.setBackgroundColor({0x00, 0x00, 0x00});
lcd.clear();
// Drawing primitives inherited from Brush
lcd.setBrushColor({0xFF, 0x00, 0x00});
lcd.drawLine({10, 10}, {100, 10});
lcd.drawCircle({60, 60}, 30);
lcd.fillRectangular({10, 110, 80, 40});
lcd.unlock();
}

Draws an RGB565 bitmap image directly onto the LCD:

  • If the bitmap extends outside the physical canvas boundaries (isOutsideCanvas() == true), calculates the clipped visible area via calculateValidArea() and streams each scanline individually with appropriate row stride offsets (mSrcOffset).

  1. Sets a 1x1 write window at (x, y) via setWindow(x, y).
  2. Issues MEMORY_WRITE (0x2C) command in register mode (TYPE_REG).

Fills a rectangular region on the display with a solid color in chunked bursts using mFb:

  1. Verifies that mFb (working framebuffer) is allocated.
  2. Calculates the maximum number of scanlines fheight that fit within mFb->getMaxPixelCount().
  3. Sets mFb dimensions to fwidth x fheight, fills mFb with color.
  4. Configures the ST7789V memory window to (x, y, width, height) and sends MEMORY_WRITE.
  5. Streams repeated chunks of mFb buffer over the bus to complete the full rectangle.
