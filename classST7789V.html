Detailed Description

Base hardware driver class for the Sitronix ST7789V TFT LCD controller.

ST7789V inherits TftLcdDriver from the TurtleShip submodule (TurtleShip/TftLcdDriver.h). It encapsulates the low-level command protocol, screen orientation control (setDirection()), and coordinate window setup (setWindow()) of the ST7789V chip.

Concrete bus implementations (such as 4-wire SPI via ST7789V_spi_with_Brush_RGB565) override the pure virtual transmission routines (sendReg(), sendData(), enable(), disable(), updateLcdSize()).

void ST7789V::setDirection ( bool xMirror,
bool yMirror,
bool rotate )

Configures display orientation, mirroring, and rotation settings via the MADCTL register.

Parameters
[in]xMirrorHorizontal mirror mode flag (true: flip X, false: normal X).
[in]yMirrorVertical mirror mode flag (true: flip Y, false: normal Y).
[in]rotateScreen rotation flag (true: landscape / 90 degree rotation, false: portrait).
Author
Yoon-Ki Hong
Date
2015
Warning
This function transmits MADCTL command to the controller; bus interface must be active.
Note
Invokes updateLcdSize() to notify derived classes of the new dimensions.
Precondition
The display interface must be initialized.
Postcondition
Panel scanning direction and canvas dimensions are updated.
Deprecated
None.

Builds the 8-bit MADCTL (Memory Data Access Control) register payload based on mirroring and rotation flags:

  • When rotate == true (landscape mode):
    • Bit 5 (MV, Row/Column Exchange) is asserted (0x20).
    • If xMirror == true, Bit 7 (MY, Row Address Order) is asserted (0x80).
    • If yMirror == true, Bit 6 (MX, Column Address Order) is asserted (0x40).
  • When rotate == false (portrait mode):
    • If xMirror == true, Bit 6 (MX) is asserted (0x40).
    • If yMirror == true, Bit 7 (MY) is asserted (0x80).

Stores the orientation in mRotateFlag, invokes updateLcdSize() to synchronize canvas dimensions, and writes the byte to the MADCTL register (0x36).

Warning

Note
Transmits COLUMN_ADDRESS_SET (0x2A) and PAGE_ADDRESS_SET (0x2B) to controller.
Precondition
Controller must be active.
Postcondition
Hardware memory write pointer is repositioned to the window boundaries.
Deprecated
None.

Sets the column and page boundaries of the drawing rectangle in ST7789V frame memory:

  • Computes endX = x + width - 1, packs [startX_MSB, startX_LSB, endX_MSB, endX_LSB] into a 4-byte buffer, and writes to COLUMN_ADDRESS_SET (0x2A).
  • Computes endY = y + height - 1, packs [startY_MSB, startY_LSB, endY_MSB, endY_LSB] into a 4-byte buffer, and writes to PAGE_ADDRESS_SET (0x2B).

Subsequent pixel write commands (e.g. MEMORY_WRITE / 0x2C) will stream pixels strictly within these boundaries.
